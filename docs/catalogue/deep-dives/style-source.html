Proposal

A · One size chosen

  • Every button is 26px, 12px text, same as fields, dropdowns and chips.
  • size goes away; 138 call sites lose it (or it's ignored).
  • Matches the "thin everywhere" choice for dropdowns and fields.
  • The primary button still stands out by colour, not by size.

B · Two sizes

  • sm 26px default everywhere.
  • md 32px kept for one place: the main action of a page or a form footer.
  • lg removed (7 uses move to md).
  • More emphasis on big actions, but two heights to keep in line.

Variants: 7 → 5

  • primary · secondary · link stay.
  • ghost becomes outline (what it looks like): a bordered, transparent button.
  • danger: one look for all 8 destructive buttons (see decision 2).
  • success removed (unused).

The same scale everywhere

  • 26px is the one control height: Button, Input, Select, DatePicker, SegmentedControl, FilterChip.
  • Icon-only controls: IconButton sm 24px, xs 18px inside rows.
  • Pills: Tag, Badge, CountBadge stay smaller (they label, they don't act).
