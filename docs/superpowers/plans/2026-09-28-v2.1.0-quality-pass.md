# v2.1.0 Quality Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clear the 2.0 backlog: arrow-key navigation on three more pages, seven correctness fixes, splits of the three largest files, and shared extraction of the duplicated receipt preview and PDF document — without changing a single generated invoice or quote.

**Architecture:** Four independent parts. The PDF work is gated behind golden snapshots captured before anything moves, so the extraction is verified as a no-op. The file splits are verbatim moves; only `NamedTable` is a real decomposition and it is the one piece allowed to be dropped if behaviour drifts.

**Tech Stack:** React 19, TypeScript, `@react-pdf/renderer`, TanStack Query, zustand, vitest + Testing Library (happy-dom), Tauri v2 SQL plugin.

**Spec:** `docs/superpowers/specs/2026-09-28-v2.1.0-quality-pass.md`

## Global Constraints

- **No generated document may change.** Invoices and quotes must render identically before and after. Stylesheet keys whose values differ between the two documents stay parametrised; values are never harmonised to each other.
- File splits are **verbatim moves**: the extracted code keeps its current implementation exactly. No tidying, renaming or "while I'm here" improvements inside a move.
- i18n: every new user-visible string goes in both the EN and FR blocks of `src/i18n/ui.ts`, FR accent-free; the parity test must stay green.
- Design system: lucide icons, `rounded-xl` cards, `rounded-lg` selects/inputs, no `gray-*` classes, all user-visible text through `useT()` or `getLabels()`.
- Gates before every commit: `npx vitest run`, `npx tsc --noEmit`, `npm run lint`. Rust is untouched by this plan; run `cargo test` only if a task edits `src-tauri/`.
- Commit messages end with the attribution lines the dispatch supplies.
- Work only in the assigned worktree. Never `cd` outside it.

```ts
  useEffect(() => { articleIdRef.current = articleId; }, [articleId]);

  const debouncedSave = useCallback(
    (content: string) => {
      if (saveTimeoutRef.current) clearTimeout(saveTimeoutRef.current);
      const scheduledFor = articleId;
      saveTimeoutRef.current = setTimeout(() => {
        // The editor may have moved to another article inside the debounce
        // window; this content belongs to the one that was open when it was
        // typed, and writing it anywhere else would corrupt that article.
        if (articleIdRef.current !== scheduledFor) return;
        updateArticle.mutate(
          { id: scheduledFor, data: { content } },
          { onError: (e) => notifyError(getLabels().operation_failed, e) }
        );
      }, 2000);
    },
    [articleId, updateArticle]
  );
```
